# Delivery roadmap

## Active browser work

- Integrate the robust narration queue, language-specific voice settings and unavailable-voice status.
- Integrate real bounded JSON/CSV conversion and safe SVG initials tools.
- Complete task-led guide, settings and personal JSON keyboard and persistence checks.
- Verify newly integrated controls in the built artifact and public deployment.
- Replace generic gap descriptions with specific next actions and platform requirements.

## Platform-dependent delivery

- Native Windows UAC and fresh-host dependency verification need an authorized Windows host.
- Native installer, signing, update and rollback require an implemented desktop product and release pipeline.
- Container companion requires a real container engine, immutable published image, Compose health and LAN checks, and a tailored native setup wizard.
- Cross-application shared mode and credential behavior require a shared native store and live watchers, not isolated browser storage.
- External forge, status and service integrations require their exact authorized connection and adapter.

## Acceptance rule

No checked box, source registry, passing unit test or browser lookalike may replace a missing runtime outcome. Keep each feature incomplete or partial until its actual implementation, documentation, localization, persistence, negative tests, interaction and capture evidence are present.
