# Changelog

## 0.1.0 initial reference implementation

- Added a browser-local task workspace, practical setup wizard, and persisted preferences.
- Added three presentation modes, independent language tone controls, accessible dialog decoration, appearance and reduced-motion settings.
- Added local task history, undo, validated backup import/export, bounded pattern searches and command palette.
- Added strict reference-extension-compatible personal JSON validation, local cache, replacement and clear behavior.
- Added four task-led walkthroughs with real-action progress and a 112-requirement acceptance reader.
- Added source-bound build provenance and the first inspected published capture.
- Added automatic, pinned Windows build dependency acquisition with native consent and explicit incomplete outcomes.
- Added isolated narrator and local conversion modules with focused tests; UI integration remains under verification.

This initial version is not full product-contract certification. The feature ledger preserves remaining implementation and evidence gaps. Native installer and complete container-companion delivery remain incomplete.
