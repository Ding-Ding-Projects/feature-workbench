Bundled offline fonts

Keeps the site's type intact offline, with no font requests to other servers.

What it must do

  • Fetch fonts with a committed script from the exact address the design uses.
  • Download every file returned, keeping weights and character ranges, and stop loudly on a partial set.
  • Record a checksum per file in a committed manifest.
  • Check fonts in the built app with the browser's font check, never by reading settings.

private-documentation-companionpendingIncomplete

Private offline documentation companion

Lets a private project ship its full documentation site as an installable offline app, instead of a public website.

What it must do

  • Package the same reviewed content a hosted site would carry: landing page, download page, every article, the full wiki and working internal links.
  • Run fully offline with no remote fonts, images or scripts.
  • Build it through the project's existing build and installer scripts, and publish it as a normal release.
  • Need no homepage URL, and never publish private content to a public host to get around hosting limits.

verifiedThe built package opened on a hidden desktop with home, article and wiki routes captured, no network requests and a clean leak scan.

Synchronized wiki and documentation

Keeps the wiki and the documentation site saying the same thing as the product, change by change.
