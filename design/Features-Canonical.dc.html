Canonical scoped project profile

Each project gets one scoped profile, so project facts never leak into global agent behaviour.

What it must do
  • Each project with stored memory owns one folder with a required, sanitized profile README.md.
  • An optional lessons.md keeps only verified methods.
  • An optional private snapshot folder is never copied into any mirror.
  • Global agent behaviour never lives there; each profile states its project-specific scope.

Canonical prompt banner

The first thing anyone sees in the shared repository is the link to the full prompt.

What it must do
  • The shared repository's README opens with a heading link to the full prompt as its very first line.
  • Nothing is ever inserted above it, including the governed vocabulary block.
  • The tool that maintains the governed block keeps it beneath the banner.

Canonical portable instruction editions

People can take the whole instruction set anywhere as a single file or a paste-ready prompt.

What it must do
  • The shared instructions are built into self-contained portable editions from one canonical source.
  • Each edition is regenerated whenever the source changes, never edited by hand.
  • Every edition states its version and the source it was built from.
  • A test confirms each edition matches the current source.
