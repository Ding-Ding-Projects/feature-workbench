Private vocabulary currency check

Builds and pushes stop when the private dictionary on this machine is out of date.

What it must do
  • Builds and pushes are held behind a lock computed at run time from the private dictionary.
  • Neither the terms nor the expected value are ever committed; the expected value lives beside the private source.
  • A missing private source is skipped with the reason printed; a present but stale lock stops the build.
  • The check says plainly that it proves the dictionary is present and current, not that anyone used it.
verifiedProof needed: The check wired into the build script and a pre-push hook; a stale lock turns the build red.
