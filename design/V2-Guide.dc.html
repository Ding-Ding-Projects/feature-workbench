Plan one useful next step

Create a task with a title and notes. Move it between To do, In progress, and Done. Edit it without leaving the workspace. Delete asks first; history lets you recover.

What you will do

  1. 1Create a task you actually want to do.
    Choose New task, enter a title, and save. Notes are optional.
  2. 2Give the task useful detail.
    Add a note, save, then reopen Edit to check it.
  3. 3Move the work forward.
    Choose In progress or Done. Undo if you moved the wrong task.

Honest by design

Browser boundaries

This is a browser-local sample, not a native application. It cannot control operating-system credentials, run installers, manage servers, or synchronize a universal lock across unrelated apps. These capabilities remain unimplemented.

Built with semantic HTML and custom CSS. Genuine Material 3 components are not installed; this is not a Material 3 compliance claim.
